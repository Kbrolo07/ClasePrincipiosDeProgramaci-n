Principios de Programación: Tu Viaje Comienza Aquí

¿Cuál es el proceso más aburrido y repetitivo que haces todos los días? ¿Cómo sería si una máquina pudiera hacerlo por ti?

Programar es...

Convertir un proceso humano (lógico y complejo) en una secuencia de instrucciones precisas que una máquina puede ejecutar (un algoritmo).

Analogía del Chef

La programación es como escribir una receta (instrucciones) muy detallada para que un ayudante (la computadora) prepare el plato (el resultado).

La Lógica del Programa: Algoritmos

Un Algoritmo es un conjunto ordenado y finito de instrucciones que nos permite resolver un problema o realizar una tarea.

Finito: Debe terminar en algún momento.

Preciso: Cada paso debe ser claro y sin ambigüedades.

Definido: Si se sigue el mismo algoritmo con la misma entrada, siempre da el mismo resultado.

Actividad: Piensa como un Algoritmo

Imaginemos que le escribimos el algoritmo a un robot para que se cepille los dientes.

Pregunta para el grupo:

¿Cuáles son los pasos exactos y ordenados que el robot debe seguir, desde que está frente al lavamanos hasta que tiene la boca limpia?

Piense en cada detalle: coger, abrir, mojar, poner... ¡No se salte ningún paso!

Algoritmo: Cepillado de Dientes (Solución)

Este es el algoritmo simple (solo secuencia, sin decisiones):

  1. Coger cepillo.
  2. Coger pasta de dientes.
  3. Destapar pasta de dientes.
  4. Poner pasta en cepillo.
  5. Tapar pasta de dientes.
  6. Mojar cepillo (opcional).
  7. Cepillar dientes.
  8. Enjuagar cepillo.
  9. Enjuagar boca.

Conclusión: Un programa es solo una lista de estos pasos, pero escritos en Sintaxis.

El Idioma de las Máquinas: Sintaxis

La Sintaxis son las reglas de gramática que debemos seguir para escribir código de forma correcta. Es el "cómo" se dicen las cosas.

Si escribes "Casa azul" en español, es correcto. Si escribes "Azul casa", la sintaxis es incorrecta, aunque se entienda la idea.

¿Qué es la Sintaxis en programación?

  • El objetivo final del programa.
  • La lógica para resolver un problema.
  • Las reglas de gramática para escribir código correcto.
  • El nombre que le damos a una variable.

Respuesta Correcta: ¡La Sintaxis son las reglas de gramática!

Explicación: Si rompes la sintaxis (ej. olvidas un paréntesis o un dos puntos), el programa mostrará un error (Syntax Error) y no se ejecutará.

1. Hablando con la Computadora: `print()`

Es la forma en que el programa nos comunica información (Salida).

Sintaxis Clave de `print()`

print( Contenido_a_Mostrar )

Regla 1: La palabra clave print debe ir en minúsculas.

Regla 2: El contenido debe ir entre paréntesis ( ).

Regla 3: Si es texto (cadenas), debe ir entre comillas " " o ' '.

print("¡Mi primer mensaje!")

¿Cuál de estas opciones tiene la sintaxis correcta en Python?

  • print("Hola")
  • Print "Hola"
  • print hola
  • print["Hola"]

Respuesta Correcta: ¡print("Hola")!

Explicación: Se requiere la palabra clave en minúsculas (print) y los paréntesis obligatorios (). Las comillas son necesarias para el texto.

2. Almacenando Información: Variables

Una Variable es una caja etiquetada en la memoria que guarda un valor. Nos ayuda a recordar datos dentro del programa.

Sintaxis Clave para Variables (Asignación)

nombre_variable = valor

Regla 1 (Asignación): Se usa el signo igual (=) para guardar o asignar un valor.

Regla 2 (Nombre): El nombre de la variable no debe tener espacios (usa _ o CamelCase).

Regla 3 (Uso): Puedes usar la variable con print() sin comillas para mostrar su valor.

mi_nombre = "Juan"
mi_edad = 25
print(mi_nombre)

¿Cuál de estas líneas es la sintaxis correcta para asignar un valor a una variable?

  • precio_final = 19.99
  • mi edad = 30 (Contiene un espacio)
  • edad := 18
  • print (nombre = "Maria")

Respuesta Correcta: ¡precio_final = 19.99!

Explicación: El nombre de la variable no tiene espacios (usa guion bajo _) y se utiliza el signo de asignación simple (=) para guardar el valor.

3. Obteniendo Datos: `input()` (Entrada)

La función `input()` permite que el programa se detenga y espere a que el **usuario ingrese datos** desde el teclado. Siempre se usa para llenar una variable.

Sintaxis Clave de `input()`

variable = input("Mensaje al usuario")

Regla 1: El resultado de `input()` debe ser guardado en una variable.

Regla 2: El mensaje que se muestra al usuario va entre comillas y dentro de paréntesis ().

nombre_usuario = input("¿Tu nombre? ")
print("Hola, " + nombre_usuario)

¿Cuál es el propósito principal de la función `input()`?

  • Mostrar un mensaje en la pantalla.
  • Asignar un valor fijo a una variable.
  • Permitir que el usuario ingrese información al programa.
  • Detener la ejecución del programa permanentemente.

Respuesta Correcta: ¡Permitir que el usuario ingrese información al programa!

Explicación: `input()` pausa la ejecución del código, le pide un dato al usuario y luego, con ese dato, continúa. Es la herramienta para la **Entrada** de datos.

4. ¡Tomando Decisiones! `if` (Condicionales)

Permite que el programa elija un camino u otro basándose en una condición (Verdadero o Falso).

Sintaxis Clave de `if`

if condicion_a_evaluar:

    codigo_si_es_verdadero

Regla 1 (Final): La condición termina obligatoriamente con dos puntos (:).

Regla 2 (Bloque): El código que se ejecuta si la condición es verdadera debe tener indentación (sangría).

Regla 3 (Comparación): Para verificar si dos valores son iguales, usamos doble igual (==).

edad = 20
if edad >= 18:
    print("Acceso permitido")
else:
    print("Acceso denegado")

¿Qué elemento de sintaxis es obligatorio al final de una línea `if` en Python?

  • Un punto y coma (;).
  • Dos puntos (:).
  • Un paréntesis de cierre ()).
  • Un signo de interrogación (?).

Respuesta Correcta: ¡Dos puntos (:)!

Explicación: Los dos puntos (:) le indican a Python que lo que sigue es un "bloque" de código que pertenece a la estructura if. Este bloque debe estar indentado.

Crea un Sistema de Acceso con Contraseña

Queremos un programa que proteja un recurso secreto. Necesitas combinar todo lo aprendido:

1. **Guardar** una contraseña secreta (Variable).

2. **Preguntar** al usuario la contraseña (Input).

3. **Decidir** si la contraseña ingresada es correcta (If/Condicional).

4. **Comunicar** el resultado: "Acceso Permitido" o "Acceso Denegado" (Print).

¿Cuál sería el Algoritmo (los pasos lógicos) para lograr esto?

Toma un momento para escribir la secuencia de pasos que le darías a la computadora.

Lógica Visual: El Diagrama de Flujo

Un Diagrama de Flujo nos ayuda a ver la lógica del algoritmo antes de programar.

Cada forma representa una acción: óvalos (inicio/fin), paralelogramos (entrada/salida), rectángulos (proceso) y diamantes (decisión).
